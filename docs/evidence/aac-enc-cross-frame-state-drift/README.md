# Cross-frame state drift evidence

Diagnostic evidence for
[`docs/aac-enc-cross-frame-state-drift-investigation.md`](../../aac-enc-cross-frame-state-drift-investigation.md).
Measurements only; no production behavior was changed.

## Method

- Rust: run the production `StreamEncoder` from frame 0 through the target
  frame. Capture the S1 inputs (`S1Cap`), post-frame `AtsElement`
  (`chaosMeasureEnFac`, `lastEnFacPatch`, `chaosMeasureOld`), pre-echo history
  (`sfbThresholdnm1`, `mdctScalenm1`, `calcPreEcho`), sequence, and emitted
  ADTS frame.
- C: parse `S1FRAME`/`S2FRAME` blocks from the full oracle dump:
  `ATS pre`, `ATS post`, `S2CHAOS pre/post`. The dump is generated by the
  pinned reference `enc_oracle`; it is not a hand-written table.
- State attribution: replay `pe_calculation` with the production S1 energy
  vectors (Rust) and with the committed C vectors (`SENL`, `PENLD`, `PTHLD`,
  `FF`, MS mask). `pe_calculation` is exact on C inputs
  (`pe::tests::s1_pe_matches_oracle_with_injected_state`), so a C-input replay
  that reproduces C `ATS post` isolates the divergence upstream of the PE
  update.
- Downstream counterfactual: inject the C post-frame ATS/chaos state at the
  first frame that consumes it, then compare every following emitted ADTS
  frame and the coded fields (`seq`, static/huff/scf/dyn, total).
- No production path was modified. The probe code used for these logs was
  removed after the permanent regression was added.

## State inventory

| State | Persistence | Read/update role |
|---|---|---|
| `BlockSwitch` `windowNrgF`, `windowNrg`, `accWindowNrg`, attack indices | all frames, per channel | recursive attack test; first decision change at speech f107 |
| `ChannelTransform` ring + MDCT overlap + `last_shape` | all frames, per channel | current-frame transform input; ring schedule is exact, MDCT parity is tolerance-gated |
| `PreEchoState` `prev`, `prev_scale`, `enabled` | all frames, per channel | previous threshold cap; exact in onset f22–f26 and within ≤25 Q31 on the rest of the scanned corpus |
| `PsyChannel.ms_ld` / `stale_ms_ld` | all frames, per channel | MS Ld history/diagnostics; short decisions use the current grouped vectors |
| `AtsElement.chaosMeasureEnFac`, `lastEnFacPatch` | per frame, per channel | `chaosMeasureEnFac` is overwritten by the current `calcWeighting`; only `lastEnFacPatch` is read as history |
| `AtsElement.chaosMeasureOld` | all frames, element-wide | VBR chaos averaging input and output |
| `DistributeState.peLast` / `dynBitsLast`, `QcState.bitResTot`, `paddingRest` | all frames | rate-control/bit-reservoir state downstream of frame sizes |

`TnsChannel` runtime decisions are cleared each frame
(`psy.rs:903-905`), so TNS is not inventoried as cross-frame state.
`PsyScratch`/S4 workspaces are reused but fully reset before use.

## Downstream counterfactual

Injection uses the C post-frame state at the first consuming frame.

| Fixture | Injected state | Frames compared | Result |
|---|---|---|---|
| onset-stereo | C f25 ATS post + C f25 S2 chaos post before f26 | f26–f28 | all emitted bytes, sequence, static/huff/scf/dyn and total fields identical |
| sweep-stereo | C f3 ATS post + C f3 S2 chaos post before f4 | f3–f10 | all emitted bytes and coded fields identical |

This does not prove perpetual harmlessness, but it establishes no local coding
consequence for the measured state differences. The frame-size differences in
these spans exist before the injected state is consumed and are therefore
upstream, not caused by the injected ATS/chaos values.

## Classification

- **No porting defect** was found in initialization, update order, reset, or
  history indexing.
- Block-switch f106/f107 is the known **numerical divergence** with a material
  sequence consequence.
- ATS `chaosMeasureEnFac` value differences are **not causal state**: the
  field is overwritten by current-frame weighting; only `lastEnFacPatch` is
  read as history, and it is exact in the scanned corpus.
- S2 `chaosMeasureOld` differences are **upstream propagation**; the S2 formula
  is exact on C inputs. No coded-output consequence was demonstrated by the
  state injection on onset f26–f28 or sweep f3–f10.
- Pre-echo state and transform ring scheduling are faithful; no material
  divergence was found there.
