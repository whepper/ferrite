## 4. TNS and S4: consequence vs coincidence

- TNS order w4 (5 vs 2): the order→bits link is proven (+18 exact). The RXX→order link is consistent-but-undemonstrated: RXX differs at w3–w7 yet orders/coefs agree exactly at w3,w5,w6,w7, localizing the flip to a marginal decision at w4 — compatible with residue-driven threshold crossing, but a live-Schur rule difference at this margin is not positively excluded by any swap experiment. Against a rule defect: live TNS detect/encode mirrors C's structure decisions identically everywhere else (placement, lengths, coefRes, all other orders/coefs bit-exact across both channels and both onset cases), which is not the signature of a broken rule.
- S4 skip at 38,39: demonstrated mechanism with exact boundary states; the 0-vs-1 energy input is consistent with propagation through post-filter energies from differing spectra. The shared 0-energy/±26k-spectra state is identical on both sides and therefore cannot explain any live-vs-C difference.
- S4 scf-search: inputs differ (proven) with an unmeasured TNS-filter-mediated component (this audit's source check); outputs differ accordingly. Live S4 is corpus-exact on reference inputs, so a rule defect would have to manifest only on these inputs for non-numeric reasons — zero positive evidence; measurable input differences suffice.
- TNS-filtering↔quantization interaction: TNS filtering changes the spectra S4 quantizes, so the dyn gaps (+205/+60) cannot be partitioned into MDCT-only vs TNS-mediated shares from existing captures. This limits causal precision, not closure: both candidate paths are numeric propagation of the same measured residue, and the bit account is exact either way.
