## 2. Capture/replay architecture

Two independent, persistent `StreamEncoder` pairs are stepped in lockstep on
identical PCM (VBR-5 operating point, both 48 kHz and 44100 Hz):

- **Full pair** (Q31-default + FPE-selected): the real production
  `step_frame` path — ADTS bytes plus `FrameSnapshot` (with the existing
  `MsDecisionCapture` and the new R2.1-B diagnostics).
- **Frontend pair** (Q31 + FPE): the real production `frontend` path,
  yielding the pre-IS working sets that `step_frame` consumes internally.

Both pairs start from fresh state and observe identical PCM, so the frontend
pair's pre-IS operands are the values the full pair's `step_frame` consumed.
This lockstep is **not trusted**: every frame replays the production
`intensity_stereo` on cloned frontend operands and asserts bit-exact
agreement with the full-encoder snapshot (books, scales, phase masks,
digest, every mutated right-channel vector vs the pre-MS capture, and
spectra unchanged on uncoded bands). Any mismatch is a `ReplayMismatch`
validation failure, never silently trusted.

MS replays the production `ms_stereo_mirror` on cloned capture operands
with the snapshot phase mask as the initial mask, asserting exact
mask/digest agreement, then recomputes the first-pass margin with exact
integer semantics and requires it to reproduce the recorded pre-upgrade
mask (the MS_ALL upgrade path is handled explicitly).

IS replay never uses Q31 operands for the FPE arm or vice versa: every
operand set carries an `EngineTag` asserted at each replay entry, and
crossed-tag inputs are proven to panic (`ownership_crossed_inputs_rejected`).

## 3. IS margin implementation (I1–I10, source-derived)

All margins preserve exact integer semantics (strict vs inclusive
comparisons, signedness, wrapping arithmetic, shift behavior) against
`intensity.rs`:

- I1 correlation: `|corr| − CORR_THRESH`, inclusive `>=` admits; `corr` from
  the production `sfb_correlation` on cloned spectra.
- I2 anti-centre: dual margins `e_l − fmult(0.7, e_r)`,
  `fmult(0.7, e_l) − e_r`; sentinel iff `m_a >= 0 && m_b <= 0`.
- I3 local error: `local_error − hrr_err[b]`, strict `<` extends.
- I4 cumulative error: `total_error − overall_after_add` with the production
  update order (the band's `hrr_err >> 3` contribution added *before* the
  comparison; arithmetic shift on possibly-negative values).
- I5 direction/stale-carry: `direction_thresh − |last − real|` with
  production `wrapping_sub`/`wrapping_neg` semantics (exact-`MIN` delta
  retains, as production does).
- I6 retention count: `count − 6` at the block boundary.
- I7 region loudness: `region_after_add − region_min` (`>> 6` accumulation).
- I8 threshold guard: dual margins `e_l − thr_l`,
  `fmult(1/1.5, e_r) − thr_r`; skip iff `m_a < 0 && m_b > 0`.
- I9 residual branch: `lr` sign selects out-of-phase (`ed`) vs in-phase
  (`es`); selected energy must be `> 0`.
- I10 clamp/rounding: dual rail margins plus exact `is_scale` recomputation
  (shift by 23, half-LSB rounding) asserted on every coded band; exact
  `real_scale = clamp(e_ld_l − e_ld_r)` asserted on every visited band; exact
  `hrr_err = fmult_div2(QUARTER − corr>>2, loudness)` asserted on every
  visited non-sentinel band.

Boundary tests cover every decision and margin at threshold ∓1/±0, including
integer-shift-aware cumulative bounds (I4/I7), stale-carry semantics (I5),
and the inclusive/exclusive edges (I1/I3/I6/I8).

## 4. Trace semantics and limitations

The trace is test-side reconstruction over the actual production decision
functions (`prepare_decisions`, `finalize_decisions`, `sfb_correlation`,
`intensity_stereo`): no permanent production instrumentation, no second IS
implementation. The authoritative decision is always the production
function's output. The trace walks bands in production update order,
recomputing the I-margins to annotate each admission, extension, rejection,
direction drop, block clear, and processing-stage drop, tracking:

- frame, group, band; operands and computed margins;
- `is_scale_last`, `real_scale`, and carry origin (group, band) — the carry
  persists across groups within a frame until a block clear resets it, and
  the clear rescan is mirrored exactly;
- cumulative extension error and region loudness with post-add order and
  no-rollback behavior;
- the first Q31↔FPE divergence and its propagation: after the first
  divergence in a group, later bands are attributed `OkPropagated` and no
  local bound is claimed.

The trace is validated against actual production outputs on both engines per
frame: the walked fate (admitted && !direction-dropped && !block-cleared) is
compared with the production mid mask at each group end; any inconsistency
fails loudly. Processing drops are attributed to geometry (degenerate band),
I8-threshold, or I9-residual without recomputing spectral sums (the residual
value itself is value territory, not re-derived).

Limitations (explicit):

- Pre-IS operands reach the trace through the lockstep frontend pair, not
  through in-`step_frame` clones (§2.4: no permanent production IS
  instrumentation). The per-frame replay-equality check is the validator for
  this indirection.
- The finalize (mid) mask has no snapshot field (only the post-processing
  phase mask escapes production, within the approved field set); it is
  reconstructed by replaying the production `finalize_decisions` on replayed
  prepare outputs, whose inputs are validated by the replay-equality chain.
  If a future change breaks that chain, the gate fails loudly rather than
  silently trusting the reconstruction.

live-encoder harness, no committed binary fixtures): sine-stereo,
onset-stereo, stepdown-stereo, multitone-stereo, tonal-noise-stereo,
quiet-sine-stereo (capped at 32 frames each where full length adds no IS/MS

quiet, and a 44100 Hz panned variant — each 12 frames with onset at frame 4
to exercise START/SHORT/STOP transitions.

Coverage achieved: IS correlation threshold boundaries (panned probes admit;
centred probes take the sentinel path), anti-centre 0.7 boundary, local and
cumulative extension-error boundaries, direction and retention-count
boundaries (extension/drop/clear events all observed), region-loudness
threshold, IS block clearing with MS_ALL interaction, quiet/sentinel cases
(silence + quiet probes, zero-energy bands), onset and step-down stereo
material, natural stereo/noise/panned material, and two sample rates.
Window coverage: LONG, SHORT, START, STOP all observed. Existing regression
fixtures are untouched.

## 6. Cause/status/consequence reporting

Independent axes; severity `N < L < P < G < F`; root cause, validation
status, and consequence recorded independently per finding:

- Cause: A (input-mapping/representation), B (numerical
  energy/psychoacoustic, incl. out-of-envelope), C (established structural
  inconsistency only — a failed bound or invalid frame never implies C),
  Unclassified (fails pending investigation).
- Validation: pass / out-of-envelope / bound-failure / domain-unsupported /
  replay-mismatch / ok-propagated.
- A bound violation is a failing validation status that fails its gate and
  triggers investigation; only evidence of an actual structural or
  implementation inconsistency assigns Cause C.
- Full event chains and the first-divergence root are preserved per frame;
  digest-only differences are structurally impossible without a coding or
  mask difference and are asserted as such (never misreported as per-band
  changes, never hidden inside digest agreement).
