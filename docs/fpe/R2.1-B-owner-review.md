## Method

The 30 findings below were extracted from a fresh read-only run of the
existing R2.1-B corpus (381 frames, 16 materials) through a temporary
print-only dump harness that re-invoked the same production replay
functions (`intensity_stereo`, `prepare_decisions`, `finalize_decisions`,
`sfb_correlation`, `ms_stereo_mirror`) and the same margin/bound
computations on the same cloned operands. The temporary harness was
removed afterwards; the implementation file was verified byte-identical
before and after (`shasum 16459f94d7ab1ec86c3b01fa82e0829cf85b2b8a`,
`cargo fmt --check` clean, 31/31 tests re-passing). No retained test or
production file differs from the R2.1-B delivery.

Per-finding fields that the current instrumentation does not record are
marked explicitly rather than inferred:

- **PE/ATS observations: UNAVAILABLE per finding.** `FrameSnapshot.pe`
  exists per frame per arm but is not attributed to findings by the
  harness; PE/ATS was diagnostic-only in R2.1-B by design (§6 scope
  exclusion). No per-finding PE/ATS value is reported below.
- **Trace event chains** are reconstructed in-test and group-end-verified
  per frame but not retained per finding; the ledger cites the validation
  points (file:line) and reproduces the decisive events where the dump
  retained them.
- **Element** is always the single stereo CPE (element 0); the harness is
  stereo-only (mono frames never reach IS/MS).

Cause/status/consequence definitions are those of R2.1-B §2.6/§3.7
(`is_ms.rs:160-230`). Severity ordering `N < L < P < G < F`.

## 2. Individual analysis of the 14 P/G findings

Common mechanism notes (cited per finding below):

- **(M1) I2 sentinel escape.** With `eR=0`, `m_a = eL − 0 = eL ≥ 0`
  always; `m_b = fmult(0x59999980, eL) − 0` is `0` for `eL=1` and `1`
  for `eL=2` (the 0.7-boundary fmult step). Q (`eL=1`) takes the
  `1/8` sentinel (`hrr=EIGHTH`, `pre=0`); FPE (`eL=2`) escapes it
  (`hrr≈10^2–10^3`, `pre=1` via `|corr|≈2.1e9 ≥ CORR_THRESH`).
  One stored LSB decides IS admission for the band.
- **(M2) Post-escape carry.** After escape, `is_scale_last`/`found`
  are set from the escaped band (origins `(0,5)` etc.), so the
  direction check retains subsequent near-identical `real_scale`
  values (`i5≈+3.1e7`, margin `≈31M` of `33.5M`). The retained block
  then codes `book 15` with `is_scale` from the exact rounding
  formula (verified per coded band in-trace, `is_ms.rs:1008`).
- **(M3) 0-vs-1 direction drop.** Stored `eR 0 vs 1` maps to Ld `MIN`
  vs `≈−1.04e9`; `real_scale` becomes `MAX-clamp 1006632960` (Q)
  vs `≈1.2e8` (FPE). Against any carried `last ≈ 1.2–1.3e8`,
  Q's deviation (`≈871M`) drops decisively while FPE's (`≈3–5M`)
  retains with `≈29–30M` margin. The carry value does not decide
  these bands (verified by substitution: swapping carries leaves
  both outcomes unchanged) — the `real_scale` values do.
- **(M4) Scale rounding.** `is_scale = ((real>>1) ± HALF_LSB) >> 23`
  (floor). One is_scale LSB `= 2^24 = 16777216` `real_scale` units.

## 4. Sentinel-domain frame (quiet-sine-stereo f16 b13)

- Identity: `quiet-sine-stereo` (dual-mono 50-LSB 1 kHz sine),
  frame 16, LONG, element CPE-0, group 0, band 13.
- Precondition failure: `ms_band_supported` (`is_ms.rs:326`) requires
  finite energy-Ld on all eight Ld operands of both arms. Here
  `es_ld = i32::MIN` on **both** arms (Q and F identical,
  `d_es = 0`): the dual-mono signal has digital-zero side energy,
  and `calc_ld_data(0)` yields the sentinel. The rule excludes the
  band regardless of which arm carries the sentinel.
- Cause class: zero-energy handling (MIN sentinel), not an
  implementation defect — both arms agree on the sentinel, the stored
  energies differ only by 1 LSB (`e 168/168` vs `169/169`), and the
  thresholds are identical (`t 168/168` both arms).
- Q/F values: `M_q = −6670` (use 0), `M_f = +121350` (use 1);
  `dEL = dER = 128019`, all other deltas 0, `B_closed = 128022`;
  measured shift `128020 ≤ B` (2 units of slack).
- IS/MS processing: IS inactive on both arms (`pre=mid=book=0`,
  sentinel `hrr=EIGHTH`, `corr=+max` both). MS decides 0 (Q) vs 1
  (F) — the sole MS-margin flip in the corpus. Coding consequence
  F-02 (`ms 0→1`); digest SOME both; frame valid/decodable.
- Applicability: the bound arithmetic is *satisfied* here (the MIN
  terms contribute identically on both arms and cancel; every
  differing term is finite), but the domain rule conservatively
  excludes any MIN-carrying band without proving that cancellation
  in general (one-sided MIN, or MIN inside a `max()` that flips the
  selected branch, is not analyzed). The bound is therefore
  **testable-but-unclaimed**: applicable on the evidence, untested
  as a general rule.
- Recommendation: **(a) explicitly retain the unsupported domain and
  document the limitation** (the implemented behavior). Do not
  silently extend `B_closed`. Propose **(b) a sentinel/zero-energy
  validation extension** as follow-up work (sound rule for
  identical-both-arms MIN terms plus one-sided-MIN analysis) to
  shrink the unsupported domain with proof, rather than by
  tolerance invention. **(c) No implementation defect** is
  indicated: the production functions behave exactly as specified
  on these inputs (replays bit-exact).
- Disposition: retain F-01/F-02 as documented Cause-B local findings
  (`DomainUnsupported` + `OutOfEnvelope`, consequence L); the frame
  stays reported, never counted as bound-validated.
- Envelope standing: `quiet-sine-stereo` is R1-gated fixture material
  (`differential.rs:119`, `run_checked` with the derived-envelope
  audit over every frame), so the underlying 1-LSB stored-energy
  difference conforms to the accepted energy envelope — F-01 is a
  within-envelope close call whose only bar to bound validation is
  the conservative MIN rule. (Probe-material energy deltas in
  F-03..F-30 are not separately envelope-adjudicated: the R2.1-B
  probes exist only in this harness. Their decision-safety evidence
  stands on exact integer margins and valid/decodable output, not
  on envelope conformance; envelope adjudication belongs to R1.)
