Scope: numerical adjudication of `docs/fpe/R2.1-B-owner-review.md` against the

No `BoundViolated`, no unsupported envelope comparison, no mapping saturation,
no accumulation wrap, no re-shift overflow, no shift-clamp exclusion, and no

is not the metric defined by §9.3.

**Consequently, the owner's status label `OutOfEnvelope` for F-03..F-30 is not
an R1 energy-envelope violation.** It is the R2.1-B decision-status label for
"no applicable decision-level (MS) bound". Every F-03..F-30 probe energy delta
is *inside* the accepted R1 envelope, at 1.04 %–3.12 % utilisation at the
finding bands (the quiet probe material's worst band reaches 7.91 %, still
inside). This distinction is currently ambiguous in the owner report and
should be stated explicitly (§6.2).

The 30 findings are numerically explained:

- the 20 long panned/out-of-phase/44.1 kHz IS findings are the I2 anti-centre
  sentinel escape at stored `eL = 1 → 2`, `eR = 0`;
- the 8 narrow SHORT findings are 1-LSB grouped stored-energy changes that
  cross the `is_scale` rounding edge or the direction threshold, with two
  zero/non-zero (Class-B) transitions;
- F-01 is a 1-LSB stored-energy difference (within the R1 envelope) whose MS
  margin flips; its B_closed arithmetic is correct, and its exclusion from the
  supported MS domain is correct and must be retained;
- F-02 is F-01's coding consequence on the same band/frame, not an independent
  numerical observation.

The most consequential numerical misstatement in the owner package is
**F-24**: the "largest energy delta, 1.5× ≈ 1.8 dB, not sub-LSB" is a 1-LSB
*stored* grouped-energy change (`eR = 2 → 3`). The 19.6 M figure is an
Ld-domain difference, not an energy delta; the R1 grouped envelope is 32.004
and the utilisation is 3.12 %. The same unit confusion affects F-19/F-23/F-25
(§6.3). This strengthens, rather than weakens, the acceptance case, but the
report must be corrected.

Recommendation in one line: **the numerical evidence is sufficient to accept
the findings as expected, envelope-conformant decision-boundary divergences;
it is not sufficient to certify perceptual neutrality (PE/ATS unavailable) or
to generalise the F-01 sentinel case, and the report needs the corrections in
§6 before owner sign-off.**

## 3. I2 sentinel escape — exact arithmetic

### 3.1 The arithmetic

`LEFT_RIGHT_RATIO_THRESH = 0x59999980 = 1,503,238,528` (the Q31 literal for
`0.7f`). Production `fmult(a,b) = floor(a·b / 2^31)`.

| eL | eR | `fmult(0.7,eR)` | `m_a = eL − fmult(0.7,eR)` | `fmult(0.7,eL)` | `m_b = fmult(0.7,eL) − eR` | sentinel `m_a ≥ 0 && m_b ≤ 0` |
|---:|---:|---:|---:|---:|---:|---|
| 0 | 0 | 0 | 0 | 0 | 0 | yes (both zero) |
| **1** | **0** | **0** | **1** | **0** | **0** | **yes** |
| **2** | **0** | **0** | **2** | **1** | **1** | **no** |

`fmult(0x59999980, 1) = 0` because the constant is below `2^31`;
`fmult(0x59999980, 2) = 1` because `2·0x59999980 = 3,006,477,056 ≥ 2^31`.
The transition is therefore exactly one stored LSB, and the inclusive `<=` on
`m_b` makes `eL = 1` a sentinel while `eL = 2` escapes it. This confirms the
owner's M1 and the "one-LSB" claim.

### 3.2 Observed transition and consequences

For F-03..F-10, F-11..F-18, F-27..F-30 the audit reproduces:

- Q31: `eL = 1`, `eR = 0`, `hrr_err = 0x10000000` (`EIGHTH`), pre-mask = 0,
  mid-mask = 0; the correlation path is skipped by the
  `if hrr_err == EIGHTH { continue; }` guard, so no I1 admission.
- FPE: `eL = 2`, `eR = 0`, finite `hrr_err` (e.g. 403 at F-03 b5, 302 at
  F-04 b13, 1,010 at F-09 b13; out-of-phase 2.8M–3.2M), mid-mask = 1;
  pre-mask = 1 for the correlation-admitted bands (all except F-29, which
  extends into an already-open block: pre = 0, mid = 1). For the admitted
  bands `|corr| ≈ 2.147e9 ≥ CORR_THRESH` (I1 margin ≈ +1.06e8 to +1.07e8).
- Trace: FPE admits or extends at the flip band (`Admit` for the
  correlation-admitted bands; `Extend` for F-29), then `CarryUpdate`; Q31 at
  the same band has no admission, and at the later b13/b15 band Q31's
  `hrr = EIGHTH` fails I3/I4 (`i3 ≈ −2.66e8`, `i4 ≈ −3.2e7`) while FPE
  extends. This is the downstream mechanism the owner describes.

The correlation is essentially identical on both arms (the out-of-phase probe
uses `corr ≈ −2.147e9`); the sentinel, not the correlation, is what differs.
The FPE pre-admission is therefore a genuine consequence of the 1→2 stored
energy, not of a different spectrum.

### 3.3 Envelope adjudication and attribution

The stored-energy comparison at these bands is:

- reference (`eL`) = 1, FPE = 2, `|Δ| = 1`;
- `Q_b ≈ 0.000–0.001`, `T_b = 0`, `R = 1.5`;
- `tol_E = max(32, Q+T+1.5) + 1/500 = 32.002`;
- utilisation **0.031248**.

So the difference is inside the R1 envelope by a factor of 32. The
decomposition identity (`delta = mapping + truncation + boundary`) passes on
every such band; the observed 1-LSB difference is the ordinary boundary
quantization: Q31 maps/rounds/floors the tiny physical band to 1, FPE rounds
the physical f64 energy to 2. It is **not** a Q31 mapping saturation, a
truncation-to-zero Class B, or an implementation defect. The owner's
attribution to the physical-f64-versus-Q31 input path is correct in substance;
the precise label is "boundary/rounding difference at a 1-LSB stored value",
not "mapping error".

### 3.4 Is the one-LSB difference acceptable?

The envelope supports the *energy* difference, not the *decision*. The I2 guard
is a hard integer threshold; any nonzero energy tolerance allows a 1-LSB
crossing at such a discontinuity. The correct statement is:

- numerically: expected and within envelope;
- decision-wise: a genuine boundary sensitivity, not a margin erosion and not a
  bound violation;
- perceptually: **not established** — PE/ATS is unavailable in the package
  (§6.5).

Accepting the flip is therefore a policy decision (Option A: retain physical
f64), not something the envelope proves. It should not be described as
"automatically acceptable" merely because it is one LSB. The owner does not
quite say that, but the report should be explicit that the energy envelope
cannot certify a decision that sits exactly on an integer threshold.

### 4.3 Numerical cause trace

The chain is:

1. **stored energy**: one LSB (grouped 4→5, 65→66, 13→14, 2→3, 58→59, 0→1);
2. **Ld**: at `E ≈ 2–5`, `d(log2 E)/dE` is large; a 1-LSB change produces
   `ΔLd ≈ 10.8M` (4→5, 1.25×, 0.97 dB) or `19.6M` (2→3, 1.5×, 1.76 dB).
   The correct conversion is `2^(ΔLd·64/2^31)`, not the owner's
   `2^(ΔLd/2147.5)` (§6.4);
3. **real_scale**: `eLd − eRd`; the difference of the two Ld deltas is
   10.06M (F-19/21), 3.59M (F-23), 19.6M (F-24), 9.97M (F-25), or the
   MAX-clamp replacement (F-20/22/26);
4. **is_scale / direction**: `real_scale` crosses the 7/8 rounding edge
   (F-19/21: 134.97M→124.91M, F-23: 124.16M→127.75M, F-24: 145.02M→125.39M,
   F-25: 129.45M→119.48M) or the direction check sees the MAX clamp vs a
   finite value. These are hard integer boundaries, not smooth margins.

All four steps are deterministic given the energies. The input differences are
1 LSB; the output differences are large only because the Ld derivative and the
decision thresholds amplify them. This is **ordinary decision-boundary
sensitivity**, not numerical error. The one exception in character is the
zero-to-one transition (F-20/22/26), where the Q31 arm's Ld is a sentinel and
the real_scale is a clamp, so the decision is structurally sensitive to the
zero/non-zero boundary; the R1 taxonomy calls this Class B (expected Q31
truncation vs FPE rounding).

- grouped Ld (energy-domain): 1.0 vs 32.000–96.130, utilisation 1.04 %–3.12 %;

### 4.5 The F-24 claim needs correction

The owner report says F-24 has "the largest energy delta in the ledger"
(`Δ≈19.6M ≈ 1.2 LSB`, "not sub-LSB"). This conflates two units:

- the **stored grouped-energy** delta is exactly **1 LSB** (`eR = 2 → 3`);
- the 19.6M number is the **Ld-domain** difference (1.5×, 1.76 dB);
- 19.6M / 2^24 = 1.17 is an `is_scale` quantum (2^24 `real_scale` units),
  not an energy LSB.

The R1 grouped envelope is 32.004, and the utilisation is 3.12 %. F-24 is not
numerically harder than F-19; it is the same 1-LSB mechanism with a smaller
`eR` (2→3 instead of 4→5), which happens to produce the largest Ld ratio. The
accept conclusion is unchanged, but the sentence "not sub-LSB" is false and
should be removed. Likewise F-19's "Δreal ≈ 0.6 LSB" is 0.6 **is_scale** LSB
(2^24 units), not 0.6 energy LSB.

## 5. F-01: MS bound and sentinel domain

### 5.1 The B_closed calculation

For F-01 (`quiet-sine-stereo f16`, LONG, band 13):

| quantity | value |
|---|---:|
| `dEL = |eldL_q − eldL_f|` | 128,019 |
| `dER` | 128,019 |
| `dEm` | 0 |
| `dEs` | 0 (`MIN` on both arms) |
| `dTL`, `dTR` | 0, 0 |
| `B = ceil((dEL+dER+dEm+dEs)/2) + dTL+dTR+2·max(dTL,dTR)+3` | **128,022** |
| `M_q` | −6,670 |
| `M_f` | +121,350 |
| measured shift | **128,020** |
| slack | **2** |

The margins reproduce by hand. With
`tldL = tldR = −792,142,351`, `min_tld = −792,142,351`, and
`max(eld, tld) = eld` on both arms:

```text
pnlr(Q) = 2·((tld>>1) − (eldL_q>>1)) = 2·(−396,071,176 + 396,013,854) = −114,644
pnms(Q) = min_tld − (emLd>>1) − (min_tld>>1)
        = −792,142,351 + 395,949,862 + 396,071,176 = −121,313
M_q     = pnms − pnlr − 1 = −121,313 + 114,644 − 1 = −6,670

pnlr(F) = 2·(−396,071,176 + 395,949,844) = −242,664
pnms(F) = −121,313  (emLd and min_tld identical)
M_f     = −121,313 + 242,664 − 1 = +121,350
```

`M_q − M_f = −128,020`, so the shift is 128,020 ≤ 128,022. The owner's numbers
are correct. The random 500,000-trial check over finite operands also never
exceeded the closed form (`worst(shift − B) = 0`), which is consistent with the
derivation: each halved term contributes at most `ceil(d/2)`, the threshold
terms propagate through both `pnms` and `pnlr`, and the `+3` covers the strict
`>` unit and the halving floors.

### 5.2 Why the identical-both-arms MIN cancellation is sound here

`es_ld = i32::MIN` on **both** arms. `min_tld` is identical on both arms
(`−792,142,351`). Therefore `max(es_ld, min_tld)` selects `min_tld` on both
arms and contributes the same `min_tld>>1` to both `pnms` values; it cancels
exactly. The same is true for `em_ld` (identical, `dEm = 0`). Every remaining
differing term is finite (`eldL`, `eldR`), and the bound covers them. The
frame-local cancellation argument is mathematically sound.

### 5.3 Why the domain rule must not be extended from this one frame

The production harness's `ms_band_supported` excludes any band with a `MIN`
sentinel in `eld_l`, `eld_r`, `em_ld`, or `es_ld` on either arm, before
`validate_ms_band` is called. F-01 is recorded `DomainUnsupported`, never
counted as validated. That is correct for three reasons:

1. A sentinel is not a log value. `dEs = |MIN − MIN| = 0` is true only because
   both arms carry the same sentinel; it is not evidence that the term is
   insensitive to a real Ld perturbation.
2. A one-sided MIN would make the `max(es, min_tld)` branch selection differ
   between arms. `dEs` would then be ≈`2^31`, and the closed form would become
   vacuous (a ~2^30 bound), not a meaningful close-call certificate. The
   formula would not necessarily produce a false `BoundViolated`, but it would
   produce a meaningless acceptance — which is worse for a validation rule.
3. A differing `min_tld` can flip the branch even with two identical sentinels.
   The F-01 proof relies on the additional coincidence that `tldL = tldR` and
   `min_tld` is identical across arms.

One observation with three coincidences cannot justify a general sentinel rule.
Retain the conservative domain, and if it is ever reduced, do it with a
branch-selection proof covering one-sided MIN and differing `min_tld`, not by
extending `B_closed`. No implementation defect is indicated: the production
functions behave exactly as specified and the replays are bit-exact.

## 6. Discrepancies and corrections to the owner package

### 6.1 Material count

`materials()` defines **15** materials (8 fixtures + silence + 6 probes), and
their frame caps sum to 381. The report's "381 frames, 16 materials" is

### 6.2 `OutOfEnvelope` is not an R1 envelope failure

The R1 audit shows every F-03..F-30 energy comparison **inside** the accepted
envelope (finding-band max utilisation 0.0312; the quiet probe material's worst
non-finding band is 0.0791, the quiet fixture 0.1176). The R2.1-B
`ValStatus::OutOfEnvelope` means "no applicable decision-level bound", not
"outside the accepted energy envelope". The report assigns that status to 23
findings (corrected count) and only §4 clarifies the R1 side; a reader will
reasonably conflate the two. Add
an explicit sentence at the top of §1 and in §6: *"OutOfEnvelope in this
ledger is a decision-safety status; the R1 energy envelope is satisfied on all
30 findings."* No code change is needed; this is report clarity only.

### 6.3 F-19/F-23/F-24/F-25 units

Replace the "≈0.2/0.6/1.2 LSB" figures for F-19, F-23, F-24 and F-25 with
`is_scale` quanta: they are `real_scale` differences divided by 2^24, not
stored-energy LSBs. The underlying stored grouped-energy deltas are exactly
1 LSB in every case, and the R1 utilisations are 1.04 %–3.12 %. In particular:

- "F-24 ... energy delta ... ≈1.2 LSB ... not sub-LSB" → "stored grouped
  energy 2→3 (1 LSB); Ld ratio 1.5×; grouped envelope 32.004; utilisation
  3.12 %";
- F-19's "Δreal ≈ 0.6 LSB" and F-25's "Δ≈10M ≈0.6 LSB" → "Δreal ≈ 0.6/0.59
  `is_scale` LSB (2^24 units), from 1-LSB stored-energy changes";
- F-23's "Δ=3.6M ≈0.2 LSB" → "Δreal ≈ 0.21 `is_scale` LSB, from a 1-LSB
  stored-energy change".

The accept conclusion is unchanged; only the unit description is wrong.

### 6.4 Ld-to-ratio formula

The report's `2^(ΔLd/2147.5)` is dimensionally wrong: with Ld in Q31 units,
`Δlog2 E = ΔLd·64/2^31`, i.e. a divisor of 33,554,432 per log2 unit, not
2,147.5. The stated ratios (1.25× and 1.50×) are correct; the formula should be
corrected. (`2,147.5 = 2^31/10^6`; it is not the per-log2-unit Ld quantum that
`ld_to_e` uses. `ld_to_e` applies `ld·64`, so the factor 64 is missing from the
reported formula.)

### 6.5 PE/ATS

The report marks PE/ATS unavailable per finding, and §6 says the P/G sign-off
is an open policy item. That is honest and should remain. But "accept" in §1/§2
should not be read as perceptual acceptance; the numerical evidence explains
the coding change, not its audibility. The owner's §6 statement that nothing is
undecided "on the evidence axis" is defensible only for the *numerical* axis:
the perceptual axis (PE/ATS) is explicitly unavailable, so it is not covered.

### 6.6 MS arithmetic on excluded bands

The "shift 369,256 ≤ B = 369,260 (4 units of slack)" for F-19 (and the
analogous F-23/F-25 numbers) is arithmetically correct but is computed on
post-IS capture operands at IS bands, which `ms_band_supported` excludes. It is
supporting evidence for margin agreement, not bound validation. The report
mostly says this; make it explicit per row so the bound is not mistaken for an
in-domain result.

### 6.7 F-02 is a consequence, not independent evidence

F-02 shares F-01's band/frame and is the MS coding consequence (`ms 0→1`). The
R1 audit covers the band's energy; the mask flip itself is deterministic given
the F-01 margin flip. This is fine, but the ledger should not count F-02 as a
second independent numerical observation.
