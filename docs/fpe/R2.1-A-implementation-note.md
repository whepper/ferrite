# R2.1-A Implementation Note — Downstream Harness and Ownership Guarantees

Date: 2026-11-18. Status: implemented, review pending. Scope: test
infrastructure only (addresses R2.0 review findings F1–F5).

No production numerical behavior, public API, dependency, or licensing change.
One production file carries an additive `#[cfg(test)]` accessor block
(`stream_driver.rs`: read-only `LiveChannel` getters + two `&mut` getters for
canary poisoning; compiled out of production builds).

## 1. What changed

- `rust/src/aac_enc/stream_driver.rs` (EXT, test-only): `#[cfg(test)] impl
  LiveChannel` with slice getters (`spec_q31`, `e_stored`, `t_stored`,
  `spread`, `e_ld`, `t_ld`, `ff`, `offsets`), scalar getters (`cnt`, `per`,
  `short`, `mdct_scale`), `tns()`, and `spec_q31_mut` / `e_stored_mut` for
  canary poisoning. Pure reads of production-built data; no logic copied.
- `rust/src/aac_enc/fpe/tests/decision.rs` (rewritten, still `#[cfg(test)]` only):
  - **Frontend layer (new, F1).** `LiveHarness` owns two `StreamEncoder`s
    (Q31 default via `with_mode(..., VbrMode::Vbr5)`; FPE via
    `EncoderConfig::...with_psy_engine(Fpe)`, same VBR-5 operating point as
    the differential harness) and steps both through production
    `frontend()` on identical PCM. Each harness's two encoders persist
    across that harness's `step_pair` calls, so histories are live across
    those calls; a tagged value holds one frame's working sets only
    (persistent state lives in the harness encoders), and an isolated
    single-frame step starts from fresh encoder state.
    `TaggedLiveInputs` wraps the owned `FrontendOut`.
    Validated per arm: spans (1024/ cnt/ cnt+1), empty-`ff` stage invariant,
    threshold-Ld floor (`≥ −33·2^25`), short-window zero-energy sentinel
    (`e_stored == 0 ⇒ e_ld == i32::MIN`), grouped-MS spans/presence, and
    exact representation geometry between arms (`cnt/per/short/offsets/
    mdct_scale/max_common`, plus bit-exact TNS history for the exercised
    frame — sine f1 case; per-frame TNS state evolution over sequences is
    covered frame-by-frame by the differential harness, `mod.rs`
    `assert_psy_state_eq` on `tns_state`/`tns_info`/MS-Ld after every
    frame). Long-window `e_ld`
    is explicitly NOT sentinel-checked: it is the float-lane rescale Ld
    (raw-energy guard + unconditional `finalShift` lift,
    `energy.rs:419-435` (Q31) / `fpe/energy.rs:122-136` (FPE), called from
    `psy.rs:767,777` / `fpe/orchestrate.rs:342,361`, plus the
    guard-free TNS overflow correction, `psy.rs:1241-1245`), so a
    zero stored band may resolve non-`MIN` Ld there (observed `-1087434918`
    on a zero band) — value territory for later stages.
  - **Ownership (F2).** All pointer checks use `.as_ptr()` with an explicit
    empty-slice guard (two empty vecs share the dangling pointer; lengths
    are asserted equal first so vacuity is exact). Extended to spectra,
    e/t/spread/e_ld/t_ld/offsets/ff, per-window psy vectors, `maxScale`,
    `nm1`, grouped vectors incl. MS halves, and `MsOutput` vectors.
    Canaries poison the actual paired arms in both directions (energy +
    spectrum on the live boundary; energy + spectrum on the psy layer) and
    verify the opposite arm byte-identical to its pre-poison snapshot.
    Crossed-input tests call the real validators (`assert_live_independent`,
    `assert_inputs_independent`) inside `catch_unwind`.
  - **Ledger (F3).** `FrameLedger { expected, processed, skipped }` with
    `record` (rejects unexpected/duplicate), `record_skip`, and
    `validate_complete` (sorted processed == expected, no skips).
    Multi-frame test steps onset-stereo 0..=30 on live encoders, validates
    every frame, and asserts short, long, START, and STOP coverage each
    independently (START/STOP tracked as their own states, never inferred
    from SHORT). Duplicate/missing/skipped/unexpected injections each fail
    loudly (unit tests).
  - **Docs (F4/F5).** Psy layer honestly documented as fresh-state-per-frame
    (supporting buffers only); frontend layer documented as the live-history
    boundary. `isolated_stage` asserts field-by-field `AtsElement`
    equivalence of the initial states; sequential test asserts cross-arm
    initial equivalence and per-arm snapshot-chain integrity. `AtsElement`
    documented as a representative state token, not real downstream state.
- No IS/MS/PE/S2/S4/S6/frame differential work (stops at the boundary).
