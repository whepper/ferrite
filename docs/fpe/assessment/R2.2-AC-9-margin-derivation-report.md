## 4. Exact derivations for the previously blocked items

### 4.1 `s2.ah_clamp_short` — Derived; owner disposition still required

Production (`threshold_vbr.rs:849–870`) uses the **within-group** loop index:

```text
group_number = sfb / sfb_per_group       // sfb is inner index => 0
gl = group_len[group_number]
scaled = fmult(thr_exp, fmult(SHORT_THR_FAC, INV_SQRT4[gl])) << 2
if scaled <= LIMIT-red: reduced = NEG_ONE
else if red >= ONE-scaled: reduced = 0
else: reduced = CalcLdData(scaled+red) << 2
reduced += CalcLdInt(gl) - AVG_COMP
margin = (reduced - weighted) - min_snr
clamp iff margin > 0 && admitted && ah_flag != NO_AH
```

Constants are exact: `SHORT_THR_FAC=0x5a3d7080`,
`INV_SQRT4=[0x7fffffff,0x7fffffff,0x6ba27e65,0x61424bb5,0x5a827999,0x55994845,0x51c8e33c,0x4eb160d1]`,
`LIMIT=0x8000`, `ONE=0x7fffffff`, `AVG_COMP=0x0c000000`.

Example exact rows from the 24-frame affected corpus:

| Witness | Q31 operands → margin | FPE operands → margin | Decision |
|---|---|---|---|
| `multitone-stereo f1 ch0 b0` | `reduced=-486577900`, `weighted=-101692959`, `min_snr=-281213728` → **−103671213** | same → **−103671213** | both do not clamp |
| `multitone-stereo f1 ch0 b1` | `reduced=-527125828`, `weighted=-368667234`, `min_snr=-144321246` → **−14137348** | same → **−14137348** | both do not clamp |

All applicable rows retain `admit`, `ah_flag`, `short`, `group_number`, and

### 4.3 S6 crash stop-distance — Derived on existing synthetic probe

Operating point: `noise-mono f5`, forced synthetic 1200-bit frame/element/
reservoir budget (`S6-PROBE-SYNTH`), explicitly not corpus evidence.

```text
term_a = (el_dyn + 8) - (bit_res_level + el_granted)
       = (2507 + 8) - (0 + 1112) = 1403
term_b = (el_dyn + el_static + 8) - max_bits_el
       = (2507 + 29 + 8) - 1200 = 1344
bits_to_save = max(term_a, term_b) = 1403
```

`bits_to_save > 0` selects crash recovery; equality/negative selects fallback.
The crash loop records 16 SFB steps and ends at survivor `maxSfb=29`:

```text
saved_final = 1437
stop_distance = saved_final - bits_to_save = 1437 - 1403 = 34
```

`34 >= 0`, so the inclusive `saved_bits >= bits_to_save` stop is met. Each
step independently satisfies:

```text
saved_before + reclaimed + side_reclaimed - saved_after = 0
```

**Classification:** Derived on the synthetic probe. The committed real corpus
has zero crashes (`S6-PROBE-CORPUS frames=20 passes=20 reduces=0 crashes=0`),
so corpus crash-distance is **Unobserved**, not zero and not Required forever.
Driver-level fallback, wipeout, exhausted search, and driver-level
QuantError/BitresTooLow remain unobserved.

## 5. Corrections and limitations found in existing evidence paths

These are factual evidence-status corrections, not production changes:

1. **Empty-population zero fabrication.** `trace.rs::tightest` uses
   `.unwrap_or((0,0))`. Empty C1/button/SHORT/LONG populations therefore render
   `Derived(0)`, falsely implying boundary equality. The new report emits only
   applicable rows. The existing collector remains a follow-up remediation.
2. **Witness loss.** `tightest` discards the witness index. The new report
   retains material/frame/channel/band/arm and exact operands.
3. **Pre/post reservoir bug.** `acct_stage_margins` reads post-S6
   `cap.acct.bit_res_tot`; the actual guards use pre-S6 `qc_pre/qc_max`. The
   report identifies the correct operands; the existing collector is not
   silently treated as authoritative for these two margins.
4. **S2 clamp-entry bug.** `r21b_s2_margin_attribution` computes the clamp
   margin from post-reduction `threshold_pre_enfac`. That is not the pre-clamp
   `reduced` operand when clamp/button/floor executes. The new report
   reconstructs the exact pre-clamp value.
5. **S2 SHORT group quirk.** Production's inner `sfb / per` yields group 0.
   The derivation preserves it; it does not “correct” it to global `s/per`.
6. **S4 sum census contamination.** PE-fail placeholder zeros are excluded
   from the new sum-margin rows (§4.2).
7. **Final-pass-only S6 collector.** Existing `element_cap`, `exit_headroom`,
   and retry margins inspect only the final pass. Existing `s6_probe` has all
   passes; a per-pass tightest sweep is a follow-up, not claimed complete.
8. **F-20/F-22/F-26 bundle payload.** The six accepted REPLAY rows prove the
   recorded mechanism and within-arm replay, but their hash payload does not
   include every printed threshold/weighted operand or pre-IS `e_l`. The
   owner acceptance record therefore cites the row identities plus the
   retained test's exact output; the bundle is not over-read.
9. **Frozen schema v2 is status-only.** FRAME/BAND rows do not carry margin
   names, values, equations, operands, or witnesses. Embedding these requires
   a new owner schema decision; this report does not smuggle a schema change.
10. **Conservative labels are not derivations.** Every FRAME row is currently
    `MarginDerivationRequired` because S4 and crash markers are unconditional;
    BAND labels are based on origin stage/sequence, not per-margin
    applicability. These labels remain unchanged and are not evidence that
    every numeric derivation is unavailable.
