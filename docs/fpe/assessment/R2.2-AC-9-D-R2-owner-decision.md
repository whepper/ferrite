# R2.2 AC-9 — D-R2 Owner Decision (27 November 2026)

**Authority:** Project owner (explicit decision dated 27 November 2026).
**Disposition:** **ACCEPT WITH DOCUMENTED LIMITATIONS — D-R2, option 1.**
**Baseline:** `189e6a79b78a84dcc5be88eaca5ffaba24097acc`.
**Scope:** The existing numerical derivation for `s2.ah_clamp_short` only.

## 1. Decision

The owner accepts the numerical derivation for `s2.ah_clamp_short` while
retaining MDEF v2's existing `Required` marker on that margin.

The accepted derivation is the exact production short-threshold chain and the
subsequent clamp decision:

```text
group_number = (sfb % sfb_per_group) / sfb_per_group   // production quirk: 0
gl = group_len[group_number]
scaled = fmult(thr_exp, fmult(SHORT_THR_FAC, INV_SQRT4[gl])) << 2
reduced = NEG_ONE if scaled <= LIMIT-red
          else 0 if red >= ONE-scaled
          else CalcLdData(scaled+red) << 2
reduced += CalcLdInt(gl) - AVG_COMP
margin = (reduced - weighted) - min_snr
clamp iff margin > 0 && admitted && ah_flag != NO_AH
```

Exact values, group identity, admission/flag state, and applicability are
retained in the AC-9 supplemental evidence
(`docs/evidence/fpe-r22-ac9/ac9-margins.tsv`, rows
`AC9-MARGIN/s2.ah_clamp_short/...`). The report records the representative
rows and the D-R2 decision package in
[`R2.2-AC-9-margin-derivation-report.md`](R2.2-AC-9-margin-derivation-report.md)
§§4.1, 10.3, and 11.

## 2. Boundaries of the decision

- The numerical derivation is accepted.
- Exact applicability and provenance are represented in the AC9 supplemental
  evidence, not inferred from the frozen labels.
- Frozen MDEF v2 and E1 schema v2 remain unchanged. The MDEF v2 `Required`
  marker on `s2.ah_clamp_short` is retained.
- No registry or schema redesign is authorized or required by this decision.
- This is a scoped decision about the existing derivation. It is not blanket
  acceptance of all `Required` margins across all operating conditions, and it
  is not acceptance of AC-9 as a whole.
