## 3. Frozen schema contract (E1-R0.3, version 2)

Pinned exactly as implemented in `evidence.rs` at the §6 hashes. Any change
to the below requires a new explicit owner decision; rows written under one
version never parse under another.

- **Schema version:** `SCHEMA_VERSION = 2`; file header `R22SCHEMA\t2`
  (byte-exact; `R22SCHEMA 1`, `R22SCHEMA\t01`, `R22SCHEMA 2` with space,
  and any other version are rejected). JSON envelope `{"schema":2,"rows":[…]}`.
- **MDEF registry:** `MDEF_VERSION = 2`, in lockstep with schema v2. Single
  source of truth for per-band margin names, owning stage, and derivation
  mode (`Direct` / `ReDerived` / `Required`); unknown names rejected, never
  guessed. `s2.ah_clamp_short` stays `Required` (OD-6, D-R2); Q-1 stays
  owner-scoped with no production change (OD-5).
- **Row family and identity** (stable deterministic IDs):
  - `R22-FRAME/{op}/{material}/{frame:06}` — one row per (OP, material,
    frame): window sequence, frame outcome (`F-even`/`F-valid`/`F-unsupported`),
    canonical R/A/S/P/F class, margin status.
  - `R22-BAND/{op}/{material}/{frame:06}/{band:03}` — one row per (OP,
    material, frame, band): producing stage, band class, margin status.
  - `R22-CHAIN/{op}/{material}/{frame:06}/{chain}/{ordinal:04}` — one row
    per propagation link (chain groups the ordered links of one flipped
    frame; dense 0-based ordinal; `Root` / `Link{stage,band}` /
    `Unattributed` provenance, never forced).
  - `R22-LEAF/{op}/{material}/{frame:06}/{band:03}/{path}` — one row per
    decomposed leaf.
  - `R22-REPLAY/{tag}` — corpus/OP-independent replay records; mismatch
    persisted before assertion (OD-7).
  - `R22-COV/{op}/{dimension}/{scope}` — per-(OP, coverage dimension,
    scope) AC-2 applicability-matrix record with explicit status marker and
    observed/required counts; per-instance COV witness bijection with
    fail-closed aggregation.
- **Total ordering** (load-bearing for byte-identical regeneration): OP
  index (OP-1…OP-6 numeric) < row-type rank
  (FRAME < BAND < CHAIN < LEAF < REPLAY < COV) < material/scope
  (byte-lexicographic) < frame (numeric) < band/ordinal (numeric) <
  trailing key. REPLAY sorts purely by tag (OP/material/frame-independent,
  so REPLAY rows never shift with corpus or OP selection). `RowSet` stores
  rows in a `BTreeMap` keyed by that order (no `HashMap` iteration) and
  rejects duplicate IDs.
- **Serialization:** TSV is UTF-8, LF-only (CRLF rejected), tab-separated,
  fixed field order (FRAME/BAND/COV 8 fields, CHAIN 9, LEAF 7, REPLAY 5),
  canonical decimal integers (no leading zeros, no `+`), canonical vectors
  (comma-joined, no spaces; absent optionals render `n/a`), explicit
  missing-evidence markers (`Missing`, `Unwired`, `Unsupported`,
  `Unobserved`, `NotApplicable`, `NotGenerated` — never reclassified),
  no embedded tabs/newlines, no trailing whitespace, trailing newline
  required, no empty lines. JSON: one object per row, fixed key order (TSV
  order prefixed by `type` and `id`), same IDs and values as TSV,
  hand-written parser (no new dependencies).
- **Validation invariants (fail closed):** unknown schema version rejected;
  CRLF rejected; missing trailing newline rejected; empty lines rejected;
  bad field counts rejected; unknown row types rejected; class/outcome/
  margin tokens validated exclusively through the reviewed Group D
  validators (E-OD-1; superseded `I` classification never accepted); stage
  tokens resolve to the reviewed `trace::Stage` (accounting keeps distinct
  `acct`, Group D `S-S6` convention retained per D-R4); ID components
  bounded and `/`-free; frame ≤ 999999, band ≤ 999, ordinal ≤ 9999;
  duplicate IDs rejected; `Direct`/`ReDerived` margins must cross-check
  exactly (`Required` stays `MarginDerivationRequired`); geometry
  serialization with stereo equality invariant; Group F placeholders remain
  `NotGenerated` (E-OD-6 / SG-3 — Group E draws no recurrence conclusions).
- **Staging:** durable write-ahead replay staging (OD-7); temperament noted
  in F-B (§2/§5).

E1 runs no corpus, generates no bundle files, and captures no production
values: every row under test is synthetic. Population from Group A capture
(E3), the bundle writer (E5), and recurrence analysis (Group F) remain
explicitly out of scope.
