## 4. Test architecture and production-path description

`DiffStream::from_pcm(display, pcm, sample_rate)`
(`tests/mod.rs`) builds the standard differential stream — persistent
per-engine `PsyChannel`/`FpeChannel` state, shared block-switch +
transform frontend, `psy::process_pair_reuse` /
`fpe::process_pair_reuse` on identical spectra — at the established
R1 operating point (VBR-5 per-channel bitrates 96000/192000 stereo,
bandwidth 19293, which equals the effective VBR-5 bandwidth at both
44100 and 48000 Hz, `min(19293, sr/2)`). `run_stream` steps every frame
plus two zero-padded tail frames with exact frame accounting
(`frames_compared == n`, `07` §7.1); `run_checked_pcm` adds the
unchanged `EnergyAudit::assert_clean` gate.

`EnergyAudit::compare_channel` is the accepted implementation,
unaltered: per-band derived envelope, collect-all failures,
energy-domain Ld comparison, retained `q31_tol` fields, three
identity gates, Class A/B sentinel classification by actual stored
state. The sole audit change is additive retention: `BandRow` records
(`audit.rs`, `rows: Vec<BandRow>`, merged in `merge()`), populated
with the retained terms (`got/want/delta/Q_b/T_b/R/tol/util`,
support flag and reason, `s_b/scale0/width/sum_abs_x` where a single
`BandEnvelope` exists). For per-window rows these are the exact
applied comparison terms; for grouped rows the retained `Q`/`T`/`R`
are sums of the per-window envelope terms while the grouped `tol`
is the sum of the applied per-window bounds (TNS-reused windows
contribute their retained `q31_tol`; see §8). `assert_clean`, aggregation, tolerances, and
the envelope math are untouched.
